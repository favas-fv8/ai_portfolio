# Contributing

Thank you for your interest in contributing to this project.

## Getting Started

1. Fork the repository.
2. Create a feature branch from `main`.
3. Install dependencies and make your changes.
4. Test the affected functionality locally.
5. Commit with a clear, descriptive message.
6. Open a pull request against `main` and explain what changed.

## Before Opening a Pull Request

Run the project's existing checks:

```bash
npm run lint
npm run build
```

Resolve any errors before submitting your pull request.

## Code Quality

- Follow the existing React and TypeScript project conventions.
- Keep changes focused and avoid unrelated modifications.
- Do not commit secrets, credentials, API keys, `.env` files, or generated artifacts.
- Update documentation when your changes affect setup or behavior.

## Pull Requests

Please include a concise summary, the testing performed, and any relevant setup notes. Include visual context when a UI change benefits from it.

## Issues

Before opening an issue, check whether a similar issue already exists. Provide clear reproduction steps for bugs and enough context to understand feature requests.
